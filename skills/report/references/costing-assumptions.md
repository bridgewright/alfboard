# Indicative Cost Assumptions

Use these values only to demonstrate a transparent planning method. They are not verified internal cost, market pricing, a quotation, or a promise of savings.

For every estimate:

1. State the role, number of working days, and daily cost assumption.
2. Show the multiplication rather than presenting only a total.
3. Separate discovery, knowledge preparation, integration, validation, enablement, and post-launch support.
4. Separate one-time implementation effort from recurring service cost.
5. Provide a range when interface quality, data readiness, or security review remains unknown.
6. Include customer-side product, operations, information-technology, security, and change-management effort where relevant.

Do not claim a margin, customer price, productivity benefit, or payback period without an explicit input and calculation. Label every resulting amount as an indicative planning assumption requiring commercial validation.
